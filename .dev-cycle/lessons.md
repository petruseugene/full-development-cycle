# dev-cycle lessons
<!-- Advisory rules learned from reviews. One lesson per line; managed by `dev-cycle lessons`. -->
- [L1] `scripts/lib/**` — When substituting shell-quoted values into a command template, reject every placeholder context that defeats single quotes (heredoc bodies, a preceding backslash), not only quoted regions; test each with a $(touch X) payload. _(2026-10-18 · prompt-slices-lessons-task-types · F1)_
- [L2] `scripts/lib/**` — Don't pass user values to a shell behind a denylist (quoting, option clusters, unlisted evaluators slip by): spawn argv with shell:false, one value per argv element, allowlist-grammar the template; some bins are sh wrappers (macOS read). _(2026-10-19 · recipe-argv-no-shell · recipe-argv)_
- [L3] `scripts/lib/**` — When a command-template grammar denies shells/interpreters, check every literal argv word, not only argv[0] (wrappers like caffeinate, arch, xcrun, sandbox-exec forward their args), and match variant names (rbash, bash5, zsh-5.9) by stem. _(2026-10-19 · recipe-argv-no-shell · F1)_
- [L4] `scripts/lib/**` — Keep one command validator per grammar and call it at spawn time for every source (profile, spec table, feature.json snapshot); a second, weaker copy used on another path silently re-opens checks the strict one closes. _(2026-10-19 · visual-tester-dashboard-insights · F1)_
- [L5] `dashboard/app/**` — When a route serves a multi-page static bundle with relative links, serve or link it at a URL whose base is the bundle folder (e.g. /x/index.html); at /x without a trailing slash, ./page.html resolves to /page.html. _(2026-10-19 · visual-tester-dashboard-insights · F2)_
- [L6] `skills/**` — Artefact paths in agent recipes must be anchored (absolute feature-folder path or a CLI placeholder like {out}), never bare relative paths: the spawning CLI or tool decides the cwd, and files land outside the self-ignored folder. _(2026-10-19 · visual-tester-dashboard-insights · F3)_
- [L7] `scripts/lib/**` — To recognise a recorded process later (PID-reuse guard), compare immutable attributes (start time, group leadership), never the command line: npm/npx and process.title rewrite argv; a mismatch must not silently drop the record. _(2026-10-19 · visual-tester-dashboard-insights · F2)_
- [L8] `scripts/lib/**` — A device/target selector only counts where the tool parses it: for tools whose selector is a global option (adb -s), require it before the subcommand; after it, the flag is passed through and the default device is used. _(2026-10-19 · visual-tester-dashboard-insights · F1)_
- [L9] `README.md`, `skills/**` — Every config or command example in docs (README JSON blocks, recipe commands) must pass the real validator in a test; a fix that documents a new pattern must also extend the grammar or it ships unusable. _(2026-10-19 · visual-tester-dashboard-insights · F3)_
- [L10] `skills/**`, `scripts/lib/cmd-feature.mjs` — When a skill's capability is folded into another skill, its dispatch condition must stay its own flag: never gate it on the host skill's flag or enablement, or a dod key that still requires it becomes unreachable. _(2026-10-19 · cost-cuts-simplify-isolation · F1)_
- [L11] `skills/**/references/**` — A reference moved to a new owner must be rewritten for the new mechanism: instructions describing steps the CLI now performs (bumps, commits) cause double execution, and its rules must match the CLI's behaviour. _(2026-10-19 · cost-cuts-simplify-isolation · F6)_
- [L12] `scripts/lib/**` — Before a destructive op (rmSync), take the confinement root from trusted config, never from the record being checked; assert its realpath is inside the repo and the target proves identity (worktree .git file -> common dir). _(2026-10-19 · worktree-isolation · F9)_
- [L13] `dashboard/lib/agent/**` — A new path that marks a live session errored must keep the offered recovery working: resume() must not short-circuit on a live errored record, and send() must not lock a session the user is told to Retry. _(2026-10-19 · dashboard-agent-optional · F1)_
