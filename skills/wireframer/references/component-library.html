Typography

When to use: every wireframe. Use h1 for page title, h2 for section, h3 for subsection. Body copy at 18px. Hand-written display font is reserved for headings + the brand mark — never run paragraphs in Caveat, it hurts readability.

Buttons

When to use: every interactive trigger that submits, navigates, or opens a flyout. Exactly one primary button per view (the desired path). Everything else is secondary or ghost. Destructive actions use the danger variant.

Variants

a11y: focus ring = dashed 3px ink, offset 3px. min-height 40px. icon-only buttons must have aria-label. disabled buttons keep their text — never just hide them.

Form fields

When to use: any data entry. Always pair <label> + control via for/id. Required fields are marked with “(required)” in the label — do not use a red asterisk alone (color-only signal).

Alerts & toasts

When to use: communicate the result of an action or system status. Alerts stay on the page until dismissed/resolved. Toasts auto-dismiss (typically 4–6s) and announce a transient event. Use exactly the icon + color + text triple — never color alone.

Modals, drawers, accordions, tooltips

When to use: a modal is a focused interruption — only for tasks that block the underlying flow. A drawer is a side panel for related context. Accordions group long-form chunks (FAQ, settings groups). Tooltips are non-essential hints — never put critical info in a tooltip.
