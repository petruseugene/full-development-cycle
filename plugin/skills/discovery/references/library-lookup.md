# Library lookup

## When to use context7

For any library, framework, SDK, API, or CLI tool — even ones you "know." Training data lags.

```
mcp__plugin_context7_context7__resolve-library-id  → get the library ID
mcp__plugin_context7_context7__query-docs           → fetch docs slice
```

## When to use WebSearch instead

- Comparing options ("X vs Y for Z")
- Recent vulnerabilities or release notes
- Community recipes / Stack Overflow patterns

## When to use WebFetch

- A specific URL (RFC, blog post, GitHub issue) the user or context7 referenced

## Citation format in `discovery.md`

```
- [context7 / <library-name>] <fact> — <one-line snippet>
- [<URL>] <fact> — <one-line snippet>
```
