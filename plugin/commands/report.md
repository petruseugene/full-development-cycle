---
description: Generate the static HTML report for this project's features and print its path.
---

Generate the report for every feature under `docs/features/` of the current project:

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/dev-cycle.mjs" report --all
```

If `${CLAUDE_PLUGIN_ROOT}` is empty, resolve the plugin directory instead:

```bash
CLI=$(find ~/.claude/plugins -maxdepth 6 -type f -path '*dev-cycle*/scripts/dev-cycle.mjs' 2>/dev/null | head -1)
node "$CLI" report --all
```

Then tell the user the report is at `.dev-cycle/report/index.html` (relative to the project root) and that it is a static page that can be opened from disk. It is regenerated by running this command again.
